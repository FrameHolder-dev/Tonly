Batch Send

The W5 smart contract standard introduces something no other wallet on TON can offer: the ability to send up to 255 messages in a single transaction. This fundamentally changes how you interact with the blockchain. Instead of signing and broadcasting one transfer at a time, Tonly lets you compose an entire batch and execute it atomically.

The use cases are immediate and practical. Payroll distribution becomes a single tap instead of dozens of repetitive transactions. Token airdrops that once took hours of manual work now complete in seconds. Splitting a dinner bill among friends no longer requires passing around a QR code one person at a time. Every recipient gets paid in the same block, with the same confirmation.

This is only possible because of how W5 restructures the wallet contract. Traditional TON wallets (V3, V4) support a single outgoing message per transaction. W5 breaks this limitation at the protocol level, allowing up to 255 outgoing messages while maintaining the same security guarantees. Each message is individually specified with its own destination, amount, and optional payload.

No other wallet in the TON ecosystem offers batch sending. Tonly is the first to bring this W5 capability to a native iOS interface, with a clean multi-recipient composer that makes the process feel as simple as sending a single payment.
