# Tonly

The first open-source TON wallet powered by the W5 standard. Fast, gasless, and built for the next generation of digital assets.

## Overview

Tonly is a native iOS wallet for the TON blockchain, built on the W5 smart contract standard. W5 enables lightning-fast transactions with gasless operations, making Tonly one of the fastest wallets in the TON ecosystem.

### iOS

The iOS app is located in `apps/ios/`. Open the Xcode project and build.

### Requirements

- Xcode 16+
- iOS 17+
- Swift 5.9+
